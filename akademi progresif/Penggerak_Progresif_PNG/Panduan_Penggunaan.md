# Penggerak Progresif — Obor Semangat

Ikon yang dipilih pengguna: obor simetris dengan api merah di tengah, api jingga di kedua sisi, serta wadah dan pegangan biru. Lettering navy mengikuti karakter profesional kelas Penggerak Progresif.

## Berkas

- Logo lengkap: ikon dengan lettering penggerak progresif di samping.
- Ikon: obor tanpa tulisan untuk avatar dan bidang kecil.
- Versi warna: untuk latar terang.
- Versi hitam: untuk penggunaan satu warna pada latar terang.
- Versi putih: masih DRAF karena artefak transparansi di tepi, celah ikon, dan lettering. Belum disarankan dipakai untuk produksi.

Semua aset dibuat menggunakan imagegen, format PNG dengan latar transparan. Bentuk dapat sedikit bervariasi antarekspor karena proses generatif; ini belum master vektor dengan geometri identik. Pertahankan rasio gambar saat memperbesar atau memperkecil. Jangan menambahkan bayangan, memiringkan ikon, atau menutup celah pemisah api.

Palet acuan: biru #2864F0, jingga #FF861C, merah #E83D3D, navy #132B54. Warna pada raster generatif dapat memiliki variasi.

Ringkasan prompt: pisahkan ikon obor pilihan 02 dari referensi, pertahankan tiga bidang api simetris, wadah dan pegangan, serta lettering profesional; buat aset logo lengkap dan ikon mandiri dalam warna, hitam, putih, dengan latar transparan.
